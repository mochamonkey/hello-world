# How to Use the Child Travel Consent Template

## Opening the Template

The `CHILD_TRAVEL_CONSENT_TEMPLATE.html` file can be opened and edited in Microsoft Word:

### Method 1: Direct Opening
1. Download the `CHILD_TRAVEL_CONSENT_TEMPLATE.html` file
2. Right-click the file and select "Open with" → "Microsoft Word"
3. The document will open in Word with full editing capabilities

### Method 2: Import into Word
1. Open Microsoft Word
2. Go to File → Open
3. Navigate to the downloaded file
4. Select "All Files (*.*)" in the file type dropdown
5. Select `CHILD_TRAVEL_CONSENT_TEMPLATE.html`
6. The document will open in Word

## Editing the Template

1. Fill in all fields marked with underlines (____________)
2. Replace all bracketed placeholders [like this] with actual information
3. The template includes:
   - Non-Traveling Parent/Guardian Information
   - Traveling Parent/Guardian Information
   - Child Information
   - Travel Information
   - Consent Statement
   - Emergency Contact Information
   - Signature Section
   - Notary Public Section

## Saving the Document

### As a Word Document (.docx)
1. Click File → Save As
2. Choose location
3. Select "Word Document (*.docx)" as file type
4. Click Save

### As a PDF (for submission)
1. Click File → Save As
2. Choose location
3. Select "PDF (*.pdf)" as file type
4. Click Save

## Important Steps Before Using

1. **Fill out completely** - Ensure all sections are completed
2. **Review carefully** - Double-check all names, dates, and passport numbers
3. **Print for notarization** - Print the document to take to a notary
4. **Get notarized** - Have a licensed notary public witness the signature
5. **Make copies** - Keep copies and carry the original when traveling

## Tips

- Use the same names as they appear on passports and birth certificates
- Complete the form in black or blue ink when signing in front of notary
- Some countries may require additional documentation (see main guide)
- Check with your airline and destination country for specific requirements
